# Simon Game 🎮

This is a browser-based clone of the Simon Game, created using **HTML**, **CSS**, and **JavaScript** (with **jQuery**). Challenge your memory skills by following the color sequence and aim to reach the highest level!

---

## Demo

To start the game, simply press any key. You will need to replicate the color sequences as they flash on the screen. The game ends if you click the wrong button.

---

## Features

- Classic Simon Game gameplay.
- Color-coded buttons: Green, Red, Yellow, and Blue.
- Audio feedback for each button click.
- Visual flashing effect for each step in the sequence.
- Levels increase as you correctly repeat the sequences.
- Game over feedback, including sound effects and background color changes.

---

## Technologies Used

- **HTML5** for the structure.
- **CSS3** for styling (utilizing a retro arcade font).
- **JavaScript** for game logic.
- **jQuery** for DOM manipulation and event handling.

---

## How to Play

1. Open `index.html` in a web browser.
2. Press any key to start the game.
3. Observe the sequence of flashing colors and repeat it by clicking the buttons in the same order.
4. Each correct sequence increases your level and adds a new color to the pattern.
5. If you make a mistake, the game will end, and you can restart by pressing any key.
